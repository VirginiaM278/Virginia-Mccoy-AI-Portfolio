Overview
Built and trained neural networks from scratch using Python and NumPy, then implemented the same models using PyTorch and TensorFlow/Keras. This project demonstrates a deep understanding of how neural networks work at a fundamental level.
Problem Statement
How do neural networks actually work under the hood? This project answers that question by building one from scratch before using industry-standard frameworks to see how they handle the same tasks behind the scenes.
Approach & Methodology

Built a neural network manually using NumPy to understand core mechanics
Rebuilt the same network using PyTorch and TensorFlow/Keras
Trained and evaluated models on the Fashion-MNIST dataset
Experimented with hyperparameters including learning rate, batch size, and epochs
Applied dropout techniques to address overfitting

Technologies Used

Python
NumPy
PyTorch
TensorFlow / Keras
Matplotlib & Seaborn
Scikit-learn

Dataset

Fashion-MNIST — 70,000 grayscale images across 10 clothing categories
Lightweight and optimized for free-tier environments (Google Colab, Kaggle)

Key Concepts Covered

Layers, neurons, and activation functions
Forward and backward propagation
Dynamic vs. static computation graphs (PyTorch vs. TensorFlow)
Overfitting and regularization with dropout
Model evaluation using classification reports and confusion matrices

How to Run

Open the .ipynb file in Google Colab or Jupyter Notebook
Run all cells in order from top to bottom
No additional setup required — all libraries are installed in the first cell

Learning Outcomes

Gained a deep understanding of what deep learning frameworks do behind the scenes
Learned to compare PyTorch and TensorFlow for different use cases
Developed skills in hyperparameter tuning and model evaluation
