Featured Projects

 Project 1 - Neural Network Foundations
Built neural networks from scratch using NumPy, then implemented the same models in PyTorch and TensorFlow. Trained on Fashion-MNIST with hyperparameter tuning and dropout regularization.
Technologies: Python, NumPy, PyTorch, TensorFlow

Project 2 - CNN Image Classification: Puppy vs Bagel
Built a CNN classifier to distinguish between puppy and bagel images using both custom architecture and transfer learning with ResNet50 and MobileNetV2.
Technologies: Python, TensorFlow, Keras, Transfer Learning

Project 3 - Diffusion Model: AI Image Generation
Implemented a diffusion model from scratch to generate handwritten digit images from pure random noise — the same core technology behind DALL-E and Stable Diffusion.
Technologies: Python, PyTorch, einops, MNIST

Project 4 - Reinforcement Learning: CartPole Agent
Implemented and compared a random agent vs. a Q-Learning agent in the CartPole-v1 environment. Explored the RL loop and its connection to RLHF in modern LLMs.
Technologies: Python, Gymnasium, NumPy, Q-Learning

 Project 5 - AI Medication Management Agent
Built a healthcare AI agent combining an LSTM deep learning model with GPT-4 to predict missed medication doses and trigger intelligent patient notifications.
Technologies: Python, TensorFlow, OpenAI API, LSTM, GPT-4
