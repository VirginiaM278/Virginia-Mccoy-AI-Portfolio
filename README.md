Featured Projects

Project 1 - Neural Network Foundations
Built neural networks from scratch using NumPy, then rebuilt the same models in PyTorch and TensorFlow. Trained on the Fashion-MNIST dataset with hyperparameter tuning and dropout regularization.
Technologies: Python, NumPy, PyTorch, TensorFlow, Keras

Project 2 - CNN Image Classification: Puppy vs Bagel
Built a CNN classifier to distinguish between puppy and bagel images using both a custom architecture and transfer learning with pre-trained models ResNet50, VGG16, and MobileNetV2.
Technologies: Python, TensorFlow, Keras, Transfer Learning, ResNet50, MobileNetV2

Project 3 - RNNs vs Transformers vs Vision Transformers
Comprehensive comparison of three major deep learning architectures — LSTM/GRU, DistilBERT, and Vision Transformer (ViT) — applied to news topic classification and image classification using the same datasets for direct benchmarking.
Technologies: Python, PyTorch, Hugging Face Transformers, DistilBERT, ViT, AG News, CIFAR-10

 Project 4 - Diffusion Model: AI Image Generation
Implemented a diffusion model from scratch to generate handwritten digit images from pure random noise — the same core technology behind DALL-E and Stable Diffusion.
Technologies: Python, PyTorch, einops, MNIST, GPU-accelerated training

 Project 5 - Reinforcement Learning: CartPole Agent
Implemented and compared a random agent vs. a Q-Learning agent in the CartPole-v1 environment. Explored the full RL loop and connected classical Q-Learning concepts to RLHF used in modern LLMs like GPT-4.
Technologies: Python, Gymnasium, NumPy, Q-Learning, Matplotlib

 Project 6 - AI Medication Management Agent
Built a healthcare AI agent combining an LSTM deep learning model with GPT-4 to monitor patient medication adherence, predict missed doses, and trigger intelligent notifications — a complete real-world AI pipeline.
Technologies: Python, TensorFlow, Keras, OpenAI API, GPT-4, LSTM, Pandas
